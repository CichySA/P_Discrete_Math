\section{Problem Overview and Motivation}

During a health crisis such as an epidemic, the rapid distribution of critical resources (e.g., vaccines, medical staff, intensive care beds) is a matter of survival. But the logistics infrastructures (roads, plains, and so on) have limited capacities and they might be issue to close some roads.

This project aims to model this logistical challenge as an optimization problem on a directed network and graph. Our objectives are to design, implement, and analyze algorithms capable of computing the maximum allocation of resources in real time in all scenario possible.

\section{Mathematical Framing and Theoretical Background}

We will use graph theory and the \textit{Max-Flow} problem to model our situation.

We will set an oriented graph $G=(V,E)$ where $V$ represents all the infrastructures (nodes) and $E$ the roads (edges). Each edge $(u,v)$ has a maximal capacity $c(u,v)$.

Our decision variable is $f(u,v)$, which represents the resources quantity on the edge $(u,v)$.

We will have two constraints:

\begin{enumerate}
    \item Capacity constraint
    \begin{equation}
        0 \leq f(u,v) \leq c(u,v)
    \end{equation}
    \item Flow conservation (Kirchhoff law)
    \begin{equation}
        \forall u \neq s,t, \quad \sum_{v \in V} f(v,u) = \sum_{v \in V} f(u,v)
    \end{equation}
    \item Flow value sign constraint
    \[
        f(u, v) \geq 0
    \]
\end{enumerate}

Our objective function is therefore to maximize the total flow leaving the source $s$:

\begin{equation}
    \max f = \sum_{v \in V} f(s,v)
\end{equation}


The main theorem that we will use is the Max-Flow theorem (see \cite{dantzig1964maxflow} and \cite{wiki_maxflow_mincut}) in order to analyze the vulnerability of the network.

We will extend this model by using a "super-source" (connected to all usines) and a "super-well" (connected to all infected zone) in order to model a multi-cluster outbreak.

We will also define and use the sensibility of an edge $c$, which is the quantity $\frac{\Delta \abs{f}}{\Delta c_c}$ and we will try to find the most vital edge.

\subsection{Max-flow min-cut}
Max-Flow problem has a corresponding dual problem - min s-t cut, which finds the minimum set of edges which, if included in the graph minimum cut, stop the flow from source s to sink t.
The decision variable \( d(u, v) \forall (u, v) \in E \) represents the\textit{potential} of flow between nodes \(u, v\).

It is subject to inequality constraints
\[
    \forall (u, v) \in E, \quad d_{uv} \geq 0
\]

The objective function is
\[
    \min \sum_{u, v \in E} d_{uv}c_{uv}
\]

\subsection{Karush-Kuhn-Tucker conditions}
KKT conditions are the necessary conditions for a solution in a Linear Program to be optimal. By using the conditions, we can describe a relationship between a LP and its dual.

First, let us describe the Lagrangian

For constraints
\[
g_i(x)\le 0,\qquad h_j(x)=0
\]

\[
\mathcal L(x,\lambda,\mu)=f(x)+\sum_i \lambda_i g_i(x)+\sum_j \mu_j h_j(x)
\]

Necessary conditions are:
\begin{itemize}
\item Stationarity

Minimization:
\[
\partial f(x^*)+\sum_i \lambda_i^*\partial g_i(x^*)+\sum_j \mu_j^*\partial h_j(x^*)=0
\]

Maximization:
\[
\partial f(x^*)-\sum_i \lambda_i^*\partial g_i(x^*)+\sum_j \mu_j^*\partial h_j(x^*)=0
\]

\item Primal feasibility

\[
g_i(x^*)\le 0,\qquad \forall i
\]

\[
h_j(x^*)=0,\qquad \forall j
\]

\item Dual feasibility

\[
\lambda_i^*\ge 0,\qquad \forall i
\]

\[
\mu_j^* \in \mathbb{R},\qquad \forall j
\]

\item Complementary slackness

\[
\lambda_i^* g_i(x^*)=0,\qquad \forall i
\]
\end{itemize}

\textbf{Substituting:}

\[
f(x) \;\longleftrightarrow\; f_{st}
\]

\[
h_j(x)
\longleftrightarrow
\sum_{(u,v)\in E} f_{uv}
-
\sum_{(v,w)\in E} f_{vw}
=0
\quad \forall v\in V\setminus\{s,t\}
\]

\[
\lambda_i \;\longleftrightarrow\; z_v
\]

\[
g_{uv}(x)
\longleftrightarrow
f_{uv}-c_{uv} \le 0
\quad \forall (u,v)\in E
\]

\[
\mu_{j} \;\longleftrightarrow\; d_{uv} \ge 0
\]

\textbf{Lagrangian:}
\[
\mathcal L(f,z,d) = f_{st}
-
\sum_{v\in V} z_v
\left(
\sum_{(u,v)\in E} f_{uv}
-
\sum_{(v,w)\in E} f_{vw}
\right)
+
\sum_{(u,v)\in E} d_{uv}(c_{uv}-f_{uv})
\]

\[ =
f_{st}
+
\sum_{(u,v)\in E}
f_{uv}(z_v - z_u - d_{uv})
+
\sum_{(u,v)\in E} c_{uv} d_{uv}.
\]

\textbf{Stationarity}
\[
\frac{\partial L}{\partial f_{uv}}
=
z_v-z_u-d_{uv}
\le 0
\qquad \forall (u,v)\in E.
\]

Equivalently,
\[
d_{uv}\ge z_v-z_u
\qquad \forall (u,v)\in E.
\]

\textbf{Dual feasibility:}
\[
d_{uv}\ge 0
\qquad \forall (u,v)\in E,
\]
\[
z_t-z_s\ge 1.
\]

\textbf{Complementary slackness:}
\[
d_{uv}(c_{uv}-f_{uv})=0
\qquad \forall (u,v)\in E.
\]

Also, for the nonnegativity constraint \(f_{uv}\ge 0\),
\[
f_{uv}\bigl(d_{uv}-(z_v-z_u)\bigr)=0
\qquad \forall (u,v)\in E.
\]
\textbf{Dual (min-cut):}
\[
\min \sum_{(u,v)\in E} c_{uv} d_{uv}
\]

subject to
\[
d_{uv} \ge z_v - z_u \quad \forall (u,v)\in E,
\]
\[
d_{uv} \ge 0 \quad \forall (u,v)\in E,
\]
\[
z_t - z_s \ge 1.
\]

For Max flow, the stationarity condition can be stated as:
\[
\partial f_{ts} -\sum \lambda_{uv}^*\partial (f_{uv} - c_{uv}) +\sum \mu_{uv}^*\partial (f_{uw} - f_{wv})
\]

For Min-cut

\partial d_{uv} + \sum \lambda_{uv}

\section{Our research goal}

\subsection{Motivation}
During initial research, it became clear that the Flow Network model has practical uses in the real world. Not only that, the problem could be extended in multiple and various ways, and transformed into a model that goes beyond simple calculation of Maximum Network Flow, which is sometimes useful.

One of the directions of inquiry is the Max Flow Min-Cut Theorem, which states that the smallest total capacity of the edges that, if cut, would stop the flow from the source to the sink, is equal to the maximum amount of flow in that network.

This is a special case of strong duality in linear programming, in which the value of the solution to one problem is equal to the other. Such a problem can be viewed from both perspectives, of the primal problem and dual problem. Constraints of the primal correspond to the variables in the dual. Why this happens, and what conditions are necessary for two problems to be connected in that way, may not be immediately obvious to a layman and can be an object of research by itself.

The mathematics get even more interesting when one looks at the issue from a more general perspective. The changing of the objective function into a \( \max \sum_{i} \log(x_i) \) can be viewed as a generalization of the Max Flow problem into one where a balance is created between fairness and the amount of flow. While this convex optimization problem formulation does not explicitly describe its dual, we can intuit there is one - unfairness must be minimized, while flow maximized (and it is indeed true, every convex problem has corresponding dual).

Both the reason why a logarithmic objective function creates such a balanced outcome, and the relation to multi-objective optimization and parametrized optimization models can be subject to research, but there is more. When talking about a min-cut problem, the fact that only edges belonging to at least one minimum cut are the bottleneck edges is useful, but even more practical might be the sensitivity analysis. The edge capacities are \textbf{constraints} in the primal problem, and the dual variables \textbf{derived} from those constraints measure the sensitivity of the network.

At the same time, while the logarithmic utility \( \sum_{i} \log(x_i) \) chosen to model fairness doesn't explicitly describe its dual, the resulting optimal solutions satisfy certain \textbf{conditions} (KKT conditions), which introduce a set of \textbf{dual variables} that allow us to analyze sensitivity of \textbf{enforcing fairness} in the same way we can analyze the sensitivity of network flow based on cut edges.

On the surface, those two problems are not strongly related, but mathematical theory shows us that there is a deep connection between varying optimization problems, and understanding the theory that leads to one problem should give us insight into both.

In the scope of this project, we propose an exploration of the mathematical problems and theorems that can give us answers to such questions as:
\begin{itemize}
    \item Why is the value of a min s-t cut equal to the maximum amount of flow in a network?
    \item Only edges belonging to at least one minimum cut can be limiting for the maximum flow?
    \item How to identify the most important edges?
    \item How does a multi-objective or parametrized problem formulations relate to duality?
    \item How understanding duality concepts, as illustrated by the max-cut min-cut theorem, help us gain insight into more general optimization problems and their sensitivity to parameters, like showing the cost of enforcing fairness in the \( \max \sum_{i} \log(x_i) \) problem?
    \item Can the answer to the above question explain why logarithmic objective leads to proportionally fair outcomes?
\end{itemize}

This project aims to highlight the unifying role of duality when applied to different optimization problems.

\subsection{Model Design and Implementation Overview for the study of sensitivity}

The implementation will be written in Python and shared through a GitHub repository, we will use \texttt{NetworkX} in order to manage graph and we will use (or implement if useful) the Edmonds-Karp algorithm.

On this basis, we will propose an algorithm to compute the min cut from a graph and perturb iteratively each edge in order to study the sensibility of the graph.

\subsection{Experiments and Results}

We will study the sensitivity on a large spectrum of graphs, where some graph have an edge with a big capacity but without any impact on the total flow if we increase that capacity.

We will also try to study how to identify the most critical edge of a graph and measure the loss of flow if we remove this edge.

Finally, we will develop an algorithm to determine an empirical evaluation of the computational cost of determining the optimal sequence of $k$ edges to increase in order to maximize gains within a limited budget.
